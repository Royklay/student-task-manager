# Student Task Manager

## Project Description

Student Task Manager is a simple web application that helps students organise and manage their daily tasks. Users can add tasks, mark them as completed, delete them, and filter tasks according to their status.

## Live Demo

[View Live Project]

## Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks from the displayed list.
- Filter tasks by All, Pending, and Completed.
- Save tasks using localStorage.
- Remember the selected filter using sessionStorage.
- Load sample tasks using the Fetch API.
- Display a welcome message using cookies.
